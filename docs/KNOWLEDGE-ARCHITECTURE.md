# Knowledge architecture

The entry skill routes tasks; references hold editorial decision procedures; profiles set genre tolerances; rules hold machine-readable catalogs; schemas validate shape; examples show counterexamples and edits.

## Provenance boundary
The user-provided anti-slop lists are editorial preferences. This repository does not establish that particular words identify a specific model, nor does it claim statistical findings from the named studies have been checked. Do not infer authorship.

## Craft sources
The reference architecture synthesizes general craft topics found in user-provided writing manuals: sound and syntax, point of view, repetition, scene and character causality, plot pacing, drafting, revision and critique. It does not reproduce copyrighted book passages or require a single plot template for all genres.

## Quality levels
1. Schema-valid: configuration parses and meets the contract.
2. Mechanically audited: literals and counts checked; false positives possible.
3. Editorially reviewed: a qualified human checks intent, causal logic, voice and exceptions.
4. Evidence verified: independently accessible sources support material nonfiction claims.
5. Empirically validated: held-out, independently annotated real writing cases show useful performance. Not achieved by shipping this repository.
