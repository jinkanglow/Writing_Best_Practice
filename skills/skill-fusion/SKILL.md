# Writing Skill Fusion

Extract primary anchors, character or claim dependencies, mandatory events, and outcome. Extract secondary forbidden expressions, voice, detail, dialogue and evidence constraints. Separate exact contradictions from semantic tensions. Translate every required abstract beat into a concrete observable scene or argument. Draft only after conflicts are resolved. Verify both the anchor and the language constraints in the finished text. The included CLI currently detects exact same-scope contradictions only; semantic translation is an agent workflow, not a verified CLI feature.
