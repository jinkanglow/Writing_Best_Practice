# Controlled editorial comparison

Status: illustrative pair only; no independent review or separate RC8/RC9 model runs have occurred.

Use the identical source packet and brief for both versions, with identical model, settings, tool access and output budget. Record skill hashes, model identifier, prompt, settings, output hashes and run date. Randomize anonymous A/B labels before review. Reviewers must not be the author or know the version mapping. Score fact retention, mechanism, authorial judgment, paragraph gain, compression and naturalness from 0–5 with exact draft excerpts and reasons. Any fabricated material fact or missing material qualifier fails regardless of score. Compare length using whitespace-delimited tokens for English, and report the convention. Record disagreements, reviewer identity and signatures using existing authenticated review tools where compatible; do not manufacture signatures. Repeat across genres and report paired results rather than claiming a universal improvement from one case.

`financial-example.md` is a manually composed demonstration using invented data. It is not a controlled model experiment.
