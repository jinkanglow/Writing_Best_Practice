# Originality review workflow

1. Confirm publisher policy and intended assistance; stop submission if prohibited.
2. Record source snapshots, attribution, author thesis and independent contribution.
3. Draft from the claim map rather than copying source sequence.
4. Run the lexical catalog and originality audit. Inspect repeated transitions, qualification clusters and duplicate paragraphs.
5. Review semantic repetition and source-outline dependence manually. Verify calculations and factual boundaries.
6. Deliver the fused article, with required attribution and disclosures. Keep review evidence separate. No detector score is a release criterion.
