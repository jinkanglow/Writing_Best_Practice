# Draft → revise → release

1. Capture purpose, genre, audience, hard facts, desired voice and mandatory anchors.
2. Load only the reference files relevant to the task; preserve the primary skill’s structure.
3. Build an anchor-to-scene or claim-to-evidence translation map before drafting.
4. Draft without inventing observations, sources or character motivation.
5. Audit factual integrity and causal continuity before cosmetic language editing.
6. Scan vocabulary and repeated structures; propose context-aware edits, preserving quotes and technical terminology.
7. Review at actual state transitions, then inspect global repetition and missing anchors.
8. Recheck edits for new defects and report deterministic vs human verification separately.
9. Do not certify literary quality, source authenticity or AI authorship from lexical checks.
